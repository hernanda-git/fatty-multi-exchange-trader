## Rework: next steps, in order

1. **Protection-verification grace** (top): bounded readback-retry (position + plans +
   capability, ~3 attempts over ~15 s) before containment; escalate only if still
   unconfirmed; raise `protection-registration-failed` so a real failure is loud.
   Tests: confirmed-late plan never closes; unconfirmed still closes; alert emitted.
2. **Closed-lifecycle terminality**: a filled entry whose position is flat with proven
   close fills must settle itself — no approved baseline required. This removes the
   last human-only exit (both of today's baselines exist only for this gap).
3. **Kernel slices 2+**: the same `park()` primitive for `console_jobs` and
   `dispatches`; then the "no absorbing state" property test that fails the build if a
   new non-terminal state can park without a deadline.
4. **Watchdog sweep** (workstream 2): stalled leases, canary exhaustion, stale fallback
   registrations (the PUMP/PENGU class retired by hand on 10‑18), and a second channel
   for delivery failures.
5. **Operator surface**: turn `scripts/requeue_late_signal.py`,
   `scripts/reconcile_unknown_intents.py` and the baseline flow into console actions,
   so nothing needs shell access.
6. Then workstreams 3–9 in `docs/MASTER-PLAN.md` (microstructure, execution quality,
   position intelligence, portfolio risk, signal scoreboard, replay harness).
